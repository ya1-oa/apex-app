# WITHERS Command — Design System v1

## Product character
WITHERS is a personal command instrument, not a generic productivity dashboard.

## Principles
1. Signal over decoration. The screen should show consequence, not card volume.
2. One active field. NOW stays intentionally small; everything else is routed elsewhere.
3. Mastery requires evidence. Generated output never counts as skill by itself.
4. Editorial hierarchy. Large decisive type, small technical metadata, sparse borders.
5. Dark technical restraint. Near-black foundation, acid signal, ice/violet supporting states.
6. Mobile is not a shrunk desktop. Bottom navigation, thumb-safe controls, no horizontal dependence.
7. Motion must communicate state. Decorative looping animation is prohibited.
8. No framework-driven visual identity. Components follow this system rather than library defaults.

## Layout grammar
- Desktop: narrow command rail + sticky top line + one primary field.
- Mobile: fixed five-destination dock.
- Command: operating window + capital signal + execution queue + domain pressure.
- Board: NOW / NEXT / INCUBATE. Dragging changes strategic state, not just position.
- Domain scores are directional state, never fake precision.
- Money view shows protected capital before discretionary goals.
- Mastery view tracks capability separately from task completion.

## AI contract
AI is a critic, coach, planner and examiner. It should ask the user to produce a hypothesis, draft, design or answer before it completes high-value learning work for them.
