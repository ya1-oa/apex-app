# WITHERS Command

Phase 1 foundation for Yakir's personal command and mastery application.

Current branch: `withers-command-v1`

Implemented:
- responsive command UI
- persistent local task state
- quick capture
- NOW / NEXT / INCUBATE drag-and-drop board
- cross-domain life map
- money/runway snapshot
- mastery tracks
- evidence-based completion progression
- human-in-the-loop coach scaffold
- dedicated production design system

Phase 2 is intentionally not mixed into this commit. It will add calendar synchronization, dynamic scheduling, reminders and collision protection.

The app currently lives under `withers-command/index.html` and does not modify the original Apex app on main.
